# 功能总览

- - -

ZEGO SDK 拥有全面覆盖全球重点区域的网络节点，提供丰富的 API，为多端提供清晰稳定的实时语音视频云服务。以下为基本 API 的简要介绍。

## 初始化相关的前置功能

| 方法名 | 描述 |
| - | - |
| [create](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/create.html) | 根据鉴权创建 Zego Effects SDK，鉴权由内部处理，用户只需传 appID 和 appSign 即可。返回创建状态，状态为 0 时表示成功，其他则失败。 |
| [destroy](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/destroy.html) | 销毁 Zego Effects SDK 实例，用于释放相关资源。 |
| [enableImageProcessing](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/enableImageProcessing.html) | 启用或禁用自定义图像处理和效果。 |
| [getAuthInfo](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/getAuthInfo.html) | 获取 SDK 授权信息，通过授权信息和 appID 可以向 ZEGO 服务器申请鉴权文件。 |
| [getResourcesFolder](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/getResourcesFolder.html) | 获取当前设备的资源路径。 |
| [getVersion](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/getVersion.html) | 获取当前 Effects SDK 版本。 |
| [initEnv](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/initEnv.html) | 初始化 Zego Effects 环境，并设置期望的分辨率。 |
| [setResources](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/setResources.html) | 设置本地素材或模型。 |
| [setResourcesPath](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/setResourcesPath.html) | 设置指定路径的素材或模型。 |
| [uninitEnv](https://doc-zh.zego.im/unique-api/ai-effects-sdk/zh/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/uninitEnv.html) | 反初始化 Zego Effects 环境。 |
