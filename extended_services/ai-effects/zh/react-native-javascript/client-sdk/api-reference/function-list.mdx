# 功能总览



- - -



ZEGO SDK 拥有全面覆盖全球重点区域的网络节点，提供丰富的 API，为多端提供清晰稳定的 AI 美颜服务。



以下为基本 API 的简要介绍。





## 初始化相关的前置功能

 | 方法名 | 描述 | 
 | --- | --- | 
 | [enableImageProcessing](./class.mdx#enableimageprocessing-zegoeffects) | 当前Effects对象绑定/解绑到Express 的自定义渲染流程.
[getAuthInfo](./class.mdx#getauthinfo-zegoeffects) | 获取 SDK 授权信息，通过授权信息和 appID 可以向 ZEGO 服务器申请鉴权文件。
[getDeviceLevel](./class.mdx#getdevicelevel-zegoeffects) | 获取设备手机性能等级。在Effects环境初始化之前部署来获取对应设备性能的效果能力。
[getVersion](./class.mdx#getversion-zegoeffects) | 获取 Effects 版本号。
[setAdvancedConfig](./class.mdx#setadvancedconfig-zegoeffects) | Effects 高级功能开关。
[setResources](./class.mdx#setresources-zegoeffects) | 设置 Effects 静态资源。
[create](./class.mdx#create-zegoeffects) | 创建 Effects 实例。
[destroy](./class.mdx#destroy-zegoeffects) | 销毁 Effects 对象。
[initEnv](./class.mdx#initenv-zegoeffects) | 初始化 Effects 引擎环境。
[uninitEnv](./class.mdx#uninitenv-zegoeffects) | 反初始化 Effects 引擎环境。
[on](./class.mdx#on-zegoeffects) | 错误信息回调。 |
