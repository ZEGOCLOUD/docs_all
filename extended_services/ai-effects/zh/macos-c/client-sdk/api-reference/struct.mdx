## zego_effects_acne_removing_param

开发者可通过该类调整祛痘斑参数。

**详情**

祛痘斑参数的系数值，通过系数值反映效果强度

<Note title="">
- **业务场景**：基础美颜效果之一
- **调用时机/通知时机**：调用setAcneRemovingParam()函数的时候传递
- **相关回调**：函数onError会吐回错误码，默认正常值是0。
</Note>

*Declared in `zego_effects_defines.h`*

### 属性

  prototype="public int intensity"
  parent_name="zego_effects_acne_removing_param"
  parent_type="class">
详情信息：痘斑去除强度，默认值为 90,范围 [0~100]。
</ParamField>

- **相关回调**：函数onError会吐回错误码，默认正常值是0。
