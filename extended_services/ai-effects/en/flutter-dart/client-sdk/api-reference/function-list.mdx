# Function Overview

- - -

The ZEGO SDK has a comprehensive network of nodes covering key areas globally, providing a rich set of APIs for multi-platforms to offer clear and stable real-time voice and video cloud services. Below is a brief introduction to the basic APIs.

## Initialization-related Preparatory Functions

| Method Name | Description |
| - | - |
| [create](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/create.html) | Create a Zego Effects SDK based on authentication. The authentication is handled internally, and users only need to pass the appID and appSign. The creation status is returned, where a status of 0 indicates success, and any other status indicates failure. |
| [destroy](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/destroy.html) | Destroy the Zego Effects SDK instance to release related resources. |
| [enableImageProcessing](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/enableImageProcessing.html) | Enable or disable custom image processing and effects. |
| [getAuthInfo](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/getAuthInfo.html) | Obtain the SDK authorization information. With the authorization information and appID, a license file can be applied for from the ZEGO server. |
| [getResourcesFolder](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/getResourcesFolder.html) | Get the resource path of the current device. |
| [getVersion](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/getVersion.html) | Get the current version of the Effects SDK. |
| [initEnv](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/initEnv.html) | Initialize the Zego Effects environment and set the desired resolution. |
| [setResources](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/setResources.html) | Set local materials or models. |
| [setResourcesPath](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/setResourcesPath.html) | Set materials or models at a specified path. |
| [uninitEnv](https://www.zegocloud.com/unique-api/ai-effects-sdk/en/dart_flutter/zego_effects_plugin/ZegoEffectsPlugin/uninitEnv.html) | Uninitialize the Zego Effects environment. |
