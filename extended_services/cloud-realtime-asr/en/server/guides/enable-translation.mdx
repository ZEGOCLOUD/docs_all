# Configure Translation

---

## Feature Overview

During real-time speech recognition (ASR), you can enable the translation feature to translate recognized audio content into the target language in real-time.
- This feature supports the following two main configuration modes:
    - **Room-level translation**: All streams in the room share one translation configuration.
    - **Stream-level translation**: Set personalized translation configurations for different streams in the room (e.g., different target languages).
- Supported translation vendors/models: Doubao doubao-seed-translation, Tongyi Qianwen Qwen-MT, and Google Translate (GoogleTranslateV2). For the translation languages supported by each vendor, refer to the official documentation of the corresponding model.
- Supported methods for obtaining translation results:
    - Server callback to get translation results.
    - Real-time audio/video room signaling (ZEGO Express SDK) callback.

## Prerequisites

1. Use a translation model supported by ZEGO cloud real-time speech recognition.
2. Have activated the service of the corresponding translation vendor and obtained the model's API Key:
<Tabs>
<Tab title="Doubao Translation">

The Volcengine Ark doubao-seed-translation model, ByteDance's self-developed multilingual translation model that supports dozens of languages with faithful and fluent translations. For details, refer to [doubao-seed-translation](https://www.volcengine.com/docs/82379/1820188?lang=zh).

</Tab>
<Tab title="Qwen Translation">

The Alibaba Cloud Bailian Qwen-MT machine translation large model, optimized based on Qwen3, supporting translation between 92 languages. For details, refer to [Translation Capability Qwen-MT](https://help.aliyun.com/zh/model-studio/machine-translation).

</Tab>
<Tab title="Google Translate">

Google Cloud Translation API (v2), which uses the nmt neural machine translation model by default and supports translation between 100+ languages. For details, refer to [Google Cloud Translation documentation](https://cloud.google.com/translate/docs).

<Warning title="Note">Google Translate is only available for scenarios where the service is deployed on overseas servers. Servers in mainland China cannot access Google services.</Warning>

</Tab>

## How to Use

When creating a real-time speech recognition task ([StartRealtimeASRTask](/cloud-realtime-asr/api-reference/start)) or adding recognition streams ([AddStream](/cloud-realtime-asr/api-reference/add-stream)), enable translation with `EnableTranslation` and configure the vendor, source language, target language, and other parameters in `Translation`:
- **Room-level translation**: Configure `EnableTranslation` and `Translation` at the task level, and all streams in the room share this translation configuration.
- **Stream-level translation**: Configure `EnableTranslation` and `Translation` for each stream in `StreamList` (e.g., different target languages). When `RecognitionRange` is `1`, the system reads the stream-level configuration first, and falls back to the outer `EnableTranslation` and `Translation` if the stream-level configuration is missing.

## Translation Parameters <a id="translation-params" />

The translation-related parameters for creating a real-time speech recognition task are as follows:

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `RecognitionRange` | Int | No | Recognition range. 0: entire room, 1: specified StreamList |
| `StreamList` | array of object | No | List of streams to recognize, effective when RecognitionRange is 1 |
| `EnableTranslation` | Bool | No | Whether to enable translation |
| `Translation` | Object | No | Translation LLM configuration item |
| `SubtitleType` | Int | No | Subtitle delivery type via room signaling, default is 0:<ul><li>0: No delivery</li><li>1: Recognition results only (e.g., when a user says "你好" in Chinese, delivers "你好")</li><li>2: Translation results only (e.g., when a user says "你好" in Chinese, delivers the translated "Hello")</li><li>3: Both recognition and translation results (e.g., when a user says "你好" in Chinese, delivers both "你好" and "Hello")</li></ul> If the client UI needs to display subtitles, it is recommended to set it to <code>1</code>, <code>2</code>, or <code>3</code> |

The translation-related parameters in `StreamList` are as follows:

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `StreamId` | String | Yes | Stream ID to recognize |
| `ASR` | Object | No | Refer to [ASR Parameters](/cloud-realtime-asr/configuring-asr#asr-params) |
| `EnableTranslation` | Bool | No | Whether to enable translation |
| `Translation` | Object | No | Translation LLM configuration item |

### Translation

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `Vendor` | String | Yes | Translation service vendor: <ul><li>`DoubaoSeedTranslation`: Doubao translation</li><li>`QwenMT`: Tongyi Qianwen translation</li><li>`GoogleTranslateV2`: Google Translate</li></ul> |
| `SourceLanguage` | String | Yes | Source language. `GoogleTranslateV2` supports omitting it or setting it to an empty string for automatic source language detection. |
| `TargetLanguage` | String | Yes | Target language |
| `LLM` | Object | Yes | LLM parameters, see the table below |

### LLM

|Parameter-100px | Type-100px | Required-100px | Description|
| :--- | :--- | :--- | :--- |
| `Url` | String | Depends on vendor | LLM endpoint, which varies by vendor:<ul><li>`DoubaoSeedTranslation`: Required, e.g., `https://ark.cn-beijing.volces.com/api/v3/responses`</li><li>`QwenMT`: Required, e.g., `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` (China site) or `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` (International site)</li><li>`GoogleTranslateV2`: Optional. If not passed, the server default endpoint is used (`https://translation.googleapis.com/language/translate/v2`)</li></ul> |
| `ApiKey` | String | No | LLM verification API key. Default is empty. Make sure to fill in the corresponding API key in production environments. |
| `Model` | String | Depends on vendor | Model to call, which varies by vendor:<ul><li>`DoubaoSeedTranslation`: Fill in the corresponding translation model, e.g., `doubao-seed-translation-250915`</li><li>`QwenMT`: Fill in the corresponding translation model, e.g., `qwen-mt-lite`</li><li>`GoogleTranslateV2`: Optional. If not passed, `nmt` is used by default</li></ul> |
| `Params` | Object | No | Request parameters for the LLM or application platform. For supported parameters, refer to the official documentation of the corresponding model. `GoogleTranslateV2` does not support passing through parameters. |

The detailed description and sample calls for each vendor are as follows (for supported translation languages, refer to each vendor's official documentation):

<Tabs titleSize="h3">
<Tab title="Doubao Translation (DoubaoSeedTranslation)">

ByteDance's self-developed multilingual translation model doubao-seed-translation, supporting dozens of languages with faithful and fluent translations. For the model introduction and supported translation languages, refer to [doubao-seed-translation](https://www.volcengine.com/docs/82379/1820188?lang=zh).

#### Sample Code

```json
{
    "EnableTranslation": true,
    "Translation": {
        "Vendor": "DoubaoSeedTranslation",
        "SourceLanguage": "zh",
        "TargetLanguage": "en",
        "LLM": {
            "Url": "https://ark.cn-beijing.volces.com/api/v3/responses",
            "ApiKey": "***",
            "Model": "doubao-seed-translation-250915",
            "Params": {}
        }
    }
}
```

</Tab>
<Tab title="Qwen Translation (QwenMT)">

The machine translation large model Qwen-MT optimized based on Qwen3, supporting translation between 92 languages, with terminology intervention, domain hints, and memory library functions. For the model introduction and supported translation languages, refer to [Translation Capability Qwen-MT](https://help.aliyun.com/zh/model-studio/machine-translation).

#### Sample Code

```json
{
    "EnableTranslation": true,
    "Translation": {
        "Vendor": "QwenMT",
        "SourceLanguage": "zh",
        "TargetLanguage": "en",
        "LLM": {
            "Url": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
            "ApiKey": "***",
            "Model": "qwen-mt-flash",
            "Params": {}
        }
    }
}
```

</Tab>
<Tab title="Google Translate (GoogleTranslateV2)">

Integrates the Google Cloud Translation API (v2), which uses the nmt neural machine translation model by default and supports translation between 100+ languages. For supported languages, refer to [Languages supported by Google Cloud Translation](https://cloud.google.com/translate/docs/languages).

Parameter description:
- Both `LLM.Url` and `LLM.Model` can be omitted: if `Url` is omitted, the server default endpoint is used; if `Model` is omitted, `nmt` is used by default.
- `ApiKey` should be the API Key of Google Cloud.
- If `SourceLanguage` is omitted or set to an empty string, the source language is detected automatically.
- Passing through parameters via `LLM.Params` is not supported.

<Warning title="Note">Google Translate is only available for scenarios where the service is deployed on overseas servers. Servers in mainland China cannot access Google services.</Warning>

#### Sample Code

```json
{
    "EnableTranslation": true,
    "Translation": {
        "Vendor": "GoogleTranslateV2",
        "SourceLanguage": "zh",
        "TargetLanguage": "en",
        "LLM": {
            "Url": "https://translation.googleapis.com/language/translate/v2",
            "ApiKey": "***",
            "Model": "nmt"
        }
    }
}
```

</Tab>

## Usage Examples

#### Start a Recognition Task with Translation and Display Translation Results on the Client
<Tabs titleSize="h5">
<Tab title="Room-level Translation (Unified Configuration)">

```json
{
    "RoomId": "room_01",
    "RecognitionRange": 0,
    "EnableTranslation": true,
    "SubtitleType": 3,//Enable this when the client needs to display translation results, set to 2 or 3
    "Translation": {
        "Vendor": "DoubaoSeedTranslation",
        "SourceLanguage": "zh",
        "TargetLanguage": "en",
        "LLM": {
            "Url": "https://ark.cn-beijing.volces.com/api/v3/responses",
            "ApiKey": "",
            "Model": "doubao-seed-translation-250915"
        }
    },
    "ASR": {
        "Vendor": "Tencent",
        "Params": {
            "EngineModelType": "16k_zh"
        }
    }
}
```


</Tab>
<Tab title="Stream-level Translation (Personalized Configuration)">


```json
{
    "RoomId": "room_02",
    "RecognitionRange": 1,
    "SubtitleType": 3, //Enable this when the client needs to display translation results, set to 2 or 3
    "StreamList": [
        {
            "StreamId": "stream_zh_01",
            "EnableTranslation": true,
            "Translation": {
                "Vendor": "DoubaoSeedTranslation",
                "SourceLanguage": "zh",
                "TargetLanguage": "en",
                "LLM": {
                    "Url": "https://ark.cn-beijing.volces.com/api/v3/responses",
                    "ApiKey": "",
                    "Model": "doubao-seed-translation-250915"
                }
            }
        },
        {
            "StreamId": "stream_en_01",
            "EnableTranslation": true,
            "Translation": {
                "Vendor": "QwenMT",
                "SourceLanguage": "Chinese",
                "TargetLanguage": "English",
                "LLM": {
                    "Url": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
                    "ApiKey": "",
                    "Model": "qwen-mt-flash"
                }
            }
        }
    ],
    "ASR": {
        "Vendor": "Tencent"
    }
}
```

<Note title="Description">When `RecognitionRange` is `1`, the system reads the stream-level configuration in `StreamList` first. If the stream-level configuration is missing, the outer `EnableTranslation` and `Translation` configurations are used as fallbacks.</Note>
