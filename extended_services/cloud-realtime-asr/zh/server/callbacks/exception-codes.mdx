# 异常事件错误码

该文档列举了实时语音识别运行过程中可能遇到的异常事件错误码，并给出了处理建议。接收异常事件的回调请参考 [接收回调](./receiving-callback.mdx)。

| 事件码 | 事件名称 | 处理建议 |
| --- | --- | --- |
| 1001 | 通用错误 | 无法细化的错误，参考异常信息描述 |
| 1004 | 服务端 VAD 检测到人声说话但是语音识别没有识别有效文本 | 统计监控或忽略不处理 |
| 1201 | RTC 通用错误 | 提供 Message 给 ZEGO 技术支持排查问题 |
| 1202 | RTC 房间空闲超出 120 秒 | 检查 RTC 房间内是否有真实用户 |
| 1204 | 登录 RTC 房间失败 | 提供 Message 给 ZEGO 技术支持排查问题 |
| 1207 | 拉流失败 | 提供 Message 给 ZEGO 技术支持排查问题 |
| 2101 | 语音识别通用错误 | 提供 Message 给 ZEGO 技术支持排查问题 |
| 2201 | 翻译 LLM 通用错误 | 无法细化的翻译错误，参考异常信息描述（Message） |
| 2202 | 翻译 LLM 参数错误 | 请检查翻译参数是否合法 |
| 2203 | 翻译 LLM 请求鉴权失败 | 请检查翻译 API Key 或账号配置 |
| 2204 | 翻译 LLM 请求并发限制 | 检查翻译服务的并发使用情况 |
| 2205 | 翻译 LLM 账号欠费 | 请检查对应厂商账号余额并及时充值 |
| 2206 | 翻译 LLM 内容审核失败 | 请检查翻译内容是否触发对应厂商的内容审核限制 |
