### 计费示例

一个房间创建云端语音识别任务，前10分钟，房间里2个人，后10分钟，房间里3个人；20分钟内的每一时刻，都只有一个人说话
因云端实时语音识别产生的计费：
1.  RTC的订阅费用：(10\*2+10\*3)/1000\*7=0.25元
2.  ASR费用：(10+10)/60\*3=1元

一共1.25元
<Note title="说明">此场景下，占用的语音识别并发为3个（房间内有3个人的声音需要被识别）</Note>

### 翻译计费说明

云端实时语音识别的翻译功能采用 **BYO-LLM（自备模型）模式**：

- 翻译模型（豆包 `doubao-seed-translation`、`Qwen-MT` 等）需您自行在模型厂商处开通服务并获取 API Key，开通与配置方式请参考 [配置翻译](/cloud-realtime-asr/guides/enable-translation)。
- 翻译调用的费用由模型厂商直接向您收取，**不经过 ZEGO 账单**；ZEGO 仅按上表计收云端语音识别费用，同时产生 RTC 的音频订阅费用。
- 各模型的单价与计费规则请以厂商官方计费文档为准：[火山方舟模型价格（豆包）](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)、[阿里云百炼模型价格（Qwen-MT）](https://help.aliyun.com/zh/model-studio/model-pricing)。

<Note title="说明">豆包 / Qwen-MT 的模型价格与计费规则由模型厂商制定并可能随时调整，请以厂商账单及官方计费文档为准。</Note>
