# 定价

<Warning title="注意">默认最大10个音频流语音识别并发。若希望增加，请联系技术支持。</Warning>

### 云端语音识别定价

| 服务细项   | 服务细项类型         | 计费模式                         | 档位   | 计费定价 | 备注                                                                                   |
| ---------- | -------------------- | -------------------------------- | ------ | -------- | -------------------------------------------------------------------------------------- |
| 基础服务   | 语音识别             | 元/小时<br/>预付费<br/>按照使用时长 | 不区分 | 3        | 1. 同时产生RTC的音频订阅费用<br/>2. 默认并发限制10<br/>3. 以实际产生的语音识别用量进行计算 |
| 增值服务   | 语音识别并发叠加包   | 元/并发/月                       | 不区分 | 100      |                                                                                        |

### 计费示例

一个房间创建云端语音识别任务，前10分钟，房间里2个人，后10分钟，房间里3个人；20分钟内的每一时刻，都只有一个人说话
因云端实时语音识别产生的计费：
1.  RTC的订阅费用：(10\*2+10\*3)/1000\*7=0.25元
2.  ASR费用：(10+10)/60\*3=1元

一共1.25元
<Note title="说明">此场景下，占用的语音识别并发为3个（房间内有3个人的声音需要被识别）</Note>

### 翻译计费说明

云端实时语音识别的翻译功能采用 **BYO-LLM（自购模型）** 模式：

- 翻译能力由第三方大模型提供，目前支持豆包 doubao-seed-translation、通义 Qwen-MT 等模型，详见 [配置翻译](/cloud-realtime-asr/guides/enable-translation)。
- 您需自行向模型厂商开通服务，并在创建识别任务时填入模型的调用地址与 API Key。

<Note title="说明">翻译模型的调用费用由模型厂商直接收取，与 ZEGO 账单无关。ZEGO 侧费用仍按上文「云端语音识别定价」收取（按识别时长计费），RTC 音频订阅费用随通话时长正常产生，开启翻译不改变上述计费规则。</Note>

各模型支持的翻译语种与价格，请参考模型厂商官方文档：

- [doubao-seed-translation（火山引擎）](https://www.volcengine.com/docs/82379/1820188?lang=zh)
- [翻译能力 Qwen-MT（阿里云百炼）](https://help.aliyun.com/zh/model-studio/machine-translation)
