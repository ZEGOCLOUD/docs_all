# Overview
- - - 
The ZEGOCLOUD Local Server Recording SDK is a recording plugin for real-time voice/video and live streaming. With simple integration and usage, it helps developers quickly and flexibly deploy local recording services to record one-on-one or many-to-many real-time voice/video calls or live streaming sessions.

The ZEGOCLOUD Local Server Recording SDK can save the content of voice chats, video chats, and live streaming, so that more people can watch it at a convenient time.

## Key Features

| Key Feature | Description | 
|--------|---------|
| Single-Stream Recording | Supports single-stream recording of each user's audio and video streams in a room. | 
| Mixed-Stream Recording | Supports mixed-stream recording of the audio and video streams of all users in a room. |
| Multi-Format Recording | Supports recording and outputting both audio and video files at the same time in a room. |
| Audio-Only Extraction | Supports extracting the audio from the audio and video streams in a room for recording. |
| Blank Frame Fill | Supports filling in blank frames for recording after a user's stream is interrupted in a room. |
| Video Screenshot | Supports taking screenshots of the audio and video of all users in a room. |
| Custom Layout | Supports custom layouts for the room video. |
| Recording Watermark | Supports adding image watermarks, text watermarks, and timestamp watermarks to the room video. |

## Use Cases

| Industry | Use Case | 
|------|--------|
| Online Education | Provides multi-party audio/video recording for online classes such as 1-on-1 tutoring, small classes, and large classes. |
| Social Live Streaming | Supports recording live streaming clips and replays, and screenshot-based content moderation. |
| Financial Services | Provides audio and video recording for video signing, remote witnessing, and other business processes for archiving. |
| Customer Service Centers | The recorded audio and video can be used for user research, customer service evaluation, and other scenarios. |
| Telemedicine | Records remote consultations and online advisory sessions for later review. |

## Product Features

| Feature | Description |
|------|-----|
| High Reliability | Supports cluster deployment and dynamic scaling to provide highly available services. |
| High Security | Provides end-to-end security mechanisms for video calls, data transmission, and data storage. |
| Adaptability | Supports recording real-time audio/video from the ZegoLiveRoom SDK, ZegoAudioRoom SDK, and ZegoExpress SDK. |
| Compatibility | Supports x86_64 Linux with glibc 2.18 or above (CentOS 7+/Ubuntu 16.04+/Debian 9+ recommended). |
| Stable and Easy to Use | Simple and easy to operate, quick to get started, and enables flexible deployment of recording services, easily implementing recording on mobile and web clients. |
| Flexible Combination | By flexibly combining various features, it can be seamlessly applied to multiple required scenarios for more comprehensive services. |
