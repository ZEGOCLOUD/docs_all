# Record Single Stream

- - - 

## Feature Overview

The Local Server Recording SDK supports recording a single audio/video stream in a room. After integrating the SDK, you can start using its single-stream recording feature.

## Prerequisites

- The ZEGOCLOUD Local Server Recording SDK has been integrated into your project. For details, see [Quick Start - Integration](./SDK%20Integration.mdx).
- You have created a project in the [ZEGOCLOUD Console](https://console.zegocloud.com) and obtained a valid AppID. For details, see "Project Information" in [Console - Project Management](/console/project-info).

## Steps

###  Set the event callback listeners

Before initializing the SDK, first call the [setZegoRoomCallback](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#setZegoRoomCallback-com.zego.zegoliveroom.callback.IZegoRoomCallback-) and [setZegoStreamRecordCallback](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#setZegoStreamRecordCallback-com.zego.zegoliveroom.callback.IZegoStreamRecordCallback-) APIs to set the room callbacks and the recording callbacks respectively, so as to receive the related event notifications during audio/video stream recording.

```java
private static IZegoRoomCallback mRoomCallback = new IZegoRoomCallback() {
    //Handle room callbacks
};

private static IZegoStreamRecordCallback mStreamRecordCallback = new IZegoStreamRecordCallback() {
    //Handle recording event callbacks
};

public void setZegoRoomCallback(IZegoRoomCallback callback)

public void setZegoStreamRecordCallback(IZegoStreamRecordCallback callback)
```
  
Before initializing the SDK, you can also call the [setLogDirAndSize](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#setLogDirAndSize-java.lang.String-long-) API as needed to set the log file path and size, which facilitates problem locating and analysis.
    
###  Initialize the SDK

Call the [initSDK](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#initSDK-long-byte:A-com.zego.zegoliveroom.callback.IZegoInitSDKCompletionCallback-) API to initialize the SDK, and pass the obtained AppID into the parameter "appID".

```java
public boolean initSDK(long appID, IZegoInitSDKCompletionCallback callback)
```

Register the asynchronous callback [onInitSDK](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/callback/IZegoInitSDKCompletionCallback.html#onInitSDK-int-) to receive the related event notifications during SDK initialization.

```java
public interface IZegoInitSDKCompletionCallback {
    void onInitSDK(int errorCode);
}
```

###  Set the Token

After initializing the SDK and before logging in to a room, call the [setToken](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#setToken-java.lang.String-java.lang.String-) API to pass in the Token you obtained for authentication.

For how to obtain the Token, see [Authenticate with Token](/local-recording-linux-java/integration/user-access-control).

```java
public void setToken(String token, String roomID)
```

###  Log in to the room

After the authentication is passed, call the [loginRoom](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#loginRoom-java.lang.String-com.zego.zegoliveroom.callback.IZegoLoginCompletionCallback-) API to log in to the room.

```java
public boolean loginRoom(String roomID, IZegoLoginCompletionCallback callback)
```

Register the asynchronous callback [onLoginCompletion](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/callback/IZegoLoginCompletionCallback.html#onLoginCompletion-int-java.lang.String-) to receive the related event notifications during room login.

```java
public interface IZegoLoginCompletionCallback {
    void onLoginCompletion(int errorCode, String roomID);
}
```

###  Start recording

After logging in to the room successfully, call the [startRecordSingleStream](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#startRecordSingleStream-java.lang.String-java.lang.String-int-int-com.zego.zegoliveroom.entity.ZegoRecordSingleStreamConfig-) API to start recording the audio/video stream.

<Note title="Note">

- It is recommended that, after logging in to the room successfully and receiving the [onStreamUpdate](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/callback/IZegoRoomCallback.html#onStreamUpdate-int-com.zego.zegoliveroom.entity.ZegoStreamInfo:A-java.lang.String-) stream information update callback notification and confirming the information of the added stream, you call the [startRecordSingleStream](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#startRecordSingleStream-java.lang.String-java.lang.String-int-int-com.zego.zegoliveroom.entity.ZegoRecordSingleStreamConfig-) API to start single-stream recording.
- Before starting recording, you can call the [getMaxRecordCount](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#getMaxRecordCount--) API to get the maximum number of streams the SDK supports recording simultaneously, and handle the number of concurrently recorded streams based on its value.
</Note>

```java
public boolean startRecordSingleStream(String streamID, String pathAndName, int muxerStreamType, int fragmentSeconds, ZegoRecordSingleStreamConfig config, String roomID)
```


Where:

- streamID: The ID of the stream you need to record.
- pathAndName: The storage path of the file generated after recording (including the file name).
    - It must end with `.mp3`/`.aac`/`.mp4`/`.flv`/`.m3u8` (`.mp3` and `.aac` only support recording pure audio).
    - The SDK automatically creates the corresponding path; if a file with the same name already exists in the path, it directly overwrites the original file.
- muxerStreamType: The type of the stream to record. See [ZegoMuxerStreamType](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/constants/ZegoMuxerStreamType.html). By default, both audio and video are recorded.
- fragmentSeconds: The fragment interval of the recording file, in seconds.
    - For the m3u8 format, the value range is [2, 60]; for other formats, the value range is [0, 10].
    - A value of 0 means no fragmentation; a value greater than 0 means fragmentation; the default value is 2.
    - Fragmentation can prevent issues where the saved recording files cannot play properly when recording is interrupted due to exceptions during the recording process.
- config: The various configurations for single-stream recording. For details, see [ZegoRecordSingleStreamConfig](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/entity/ZegoRecordSingleStreamConfig.html).
  
<Warning title="Note">

`Fragmentation` is a logical concept for the SDK to process recording files internally, and does not split the recorded file into multiple small files by interval for storage.  
</Warning>

Register the asynchronous callback [onStreamRecordBegin](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/callback/IZegoStreamRecordCallback.html#onStreamRecordBegin-java.lang.String-java.lang.String-) to receive the related event notifications during recording.

```java
public interface IZegoStreamRecordCallback {

    void onStreamRecordBegin(String streamID, String pathAndName);
}
```

After recording starts successfully, the [onStreamRecordBegin](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/callback/IZegoStreamRecordCallback.html#onStreamRecordBegin-java.lang.String-java.lang.String-) callback is received.
          
###  Stop recording

When recording is no longer needed or is completed, call the [stopRecordSingleStream](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#stopRecordSingleStream-java.lang.String-) API to stop recording.

```java
public boolean stopRecordSingleStream(String streamID)
```

Register the asynchronous callback [onStreamRecordEnd](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/callback/IZegoStreamRecordCallback.html#onStreamRecordEnd-java.lang.String-java.lang.String-int-) to receive the related event notifications when recording is stopped.
 
```java
public interface IZegoStreamRecordCallback {
    void onStreamRecordEnd(String streamID, String pathAndName, int reason);
}
```
 
Then:

1. Call the [logoutRoom](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#logoutRoom--) API to exit the room.
2. Call the [setZegoRoomCallback](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#setZegoRoomCallback-com.zego.zegoliveroom.callback.IZegoRoomCallback-)(null) and [setZegoStreamRecordCallback](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#setZegoStreamRecordCallback-com.zego.zegoliveroom.callback.IZegoStreamRecordCallback-)(null) APIs to stop the callback listeners.
3. Call the [unInitSDK](https://doc-zh.zego.im/API/ServerRecord-java-en/html/com/zego/zegoliveroom/ZegoLiveRoom.html#unInitSDK--) API to uninitialize the SDK.
