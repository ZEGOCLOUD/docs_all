# 概述

- - -

## 产品简介

ZEGO 数字人 API 依托即构自研 AI 引擎，开发者可定制生成自然生动的数字人形象。搭配实时互动 AI Agent 方案，可快速实现数字人 AI 互动对话、实时播报等场景，灵活适配 AI 陪伴、智能客服、直播电商、AI 教师等多元业务场景。

## 产品优势

### 媲美真人的数字人形象

基于 ZEGO 自研数字人形象生成引擎，开发者可实现图片数字人、真人数字人2种形象定制服务。
- 图片数字人（推荐）：只需一张图片，经过 AI 训练即可让图片“活”过来，图片支持真人、卡通、虚拟人等各类形象；生成的形象口齿清晰、表情自然、并能具有一定的自然动作、活泼生动。
- 真人数字人：采集一段真人拍摄视频，经过 AI 训练后生成神态、动作、表情媲美真人的数字人，可自定义背景、支持最高2k超清画质、支持自定义动作驱动，数字人形象逼真，效果自然。

### 结合实时互动 AI Agent，全链路开箱即用

- 数字人 AI 互动对话、实时播报等互动场景，推荐接入实时互动 AI Agent 方案：依托 Agent 一站式完成 ASR、大模型推理、TTS 与数字人驱动全链路，无需业务侧串联多个 AI 组件。
- 具备更低交互延迟、数字人口型表情表现更自然、产品功能持续迭代升级等优势，并支持更灵活的音色配置。
- 极致性价比：超低价格、支持大并发，满足用量较大的互动对话、互动教学等场景，帮助业务极致降本。
