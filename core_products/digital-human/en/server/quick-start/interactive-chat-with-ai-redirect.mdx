ZEGO recommends using the real-time interactive AI Agent solution to implement AI interactive chat with digital humans. This solution relies on the Agent to complete the full ASR, LLM inference, TTS, and digital human driving pipeline in one stop, without requiring the business side to connect multiple AI components.
