<Note title="Note">
- The ZIM SDK for Flutter comes in the following two versions:
  - Not applicable to HarmonyOS: supports app development for iOS, Android, macOS, Windows, and Web.
  - Applicable to HarmonyOS: supports app development for iOS, Android, HarmonyOS, macOS, Windows, and Web. This SDK depends on [Flutter adapted for OpenHarmony](https://gitee.com/openharmony-sig/flutter_flutter).
- The ZPNs SDK encapsulates the offline push notification capabilities of mainstream mobile phone manufacturers, supporting push notifications from Huawei, Xiaomi, OPPO, vivo, Apple, and Google. Developers can choose whether to integrate the ZPNs SDK based on business needs.
- The ZPNs SDK currently supports Android, iOS, Flutter, Web, React Native, uni-app, and uni-app x platforms. For details, refer to [Implement offline push notification](./../Offline%20push%20notifications/Implement%20offline%20push%20notification.mdx).
</Note>
