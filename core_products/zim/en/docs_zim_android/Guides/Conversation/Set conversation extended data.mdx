# Set conversation extended data

- - -

## Introduction

The conversation extended data (`extendedData`) is a JSON string customized and maintained by the business side. It can be attached to a conversation to store custom business data of the conversation.

Starting from version 3.3.0, ZIM supports setting extended data for conversations. Once set, the extended data is returned through the `extendedData` field of [ZIMConversation](@-ZIMConversation) when querying the conversation list or receiving a conversation changed notification.

<Note title="Note">

The conversation extended data and the conversation mark are independent of each other: setting or unsetting a conversation mark does not clear the conversation extended data.
</Note>

## Procedures

Call the {getPlatformData(props,setConversationExtendedDataMap)} interface and pass in a list of [ZIMConversationExtendedData](@-ZIMConversationExtendedData) (containing the conversation ID, conversation type, and extended data) to set the extended data of multiple conversations in batches. Pass an empty string as `extendedData` to delete the extended data of the corresponding conversation.

**Notes:**

- Only one-on-one and group chat conversations are supported. For other conversation types (such as rooms), the setting fails locally.
- Even if `errorInfo.code` in the callback indicates success, you should still check `failedConversationInfos`; the entries rejected locally are returned in this list.

```java
// Build the conversation extended data list
ArrayList<ZIMConversationExtendedData> extendedDataList = new ArrayList<>();
ZIMConversationExtendedData data = new ZIMConversationExtendedData();
data.setConversationID("convId");
data.setConversationType(ZIMConversationType.PEER);
data.setExtendedData("{\"key\":\"value\"}");
extendedDataList.add(data);

// Set the conversation extended data
zim.setConversationExtendedData(extendedDataList, new ZIMConversationExtendedDataSetCallback() {
    @Override
    public void onConversationExtendedDataSet(ArrayList<ZIMConversationBaseInfo> failedConversationInfos, ZIMError errorInfo) {
        // Callback for the result of setting the conversation extended data
        // failedConversationInfos is the list of base information of the conversations that failed to be set
    }
});
```
