# Query a conversation

- - -

## Introduction

ZIM supports querying detailed information of a single conversation by specifying the conversation ID, and also supports querying detailed information of multiple specified conversations in batches.

## Query a single conversation

After the login, a user can use the {getPlatformData(props,queryConversationMap)} interface to specify the conversation ID and conversation type to get detailed information about the corresponding conversation, including the conversation name, unread count, and notification status.

## Batch query conversations

Starting from version 3.3.0, ZIM supports querying conversations in batches.

After the login, a user can call the {getPlatformData(props,queryConversationsMap)} interface and pass in the list of conversation base information to be queried ([ZIMConversationBaseInfo](@-ZIMConversationBaseInfo)), to get detailed information of multiple specified conversations at once (including the conversation name, unread count, and notification status), without calling the {getPlatformData(props,queryConversationMap)} interface multiple times.

- Up to 100 conversations can be queried at a time. This feature is available after login and unavailable after logout.
- Successfully queried conversations are returned through `conversations` in the callback, and the conversation base information that failed to be queried is returned through `errorConversationInfos`, based on which you can retry or degrade the process.

:::if{props.platform=undefined}
```java
// Build the list of conversation base information to be queried
ArrayList<ZIMConversationBaseInfo> conversationInfos = new ArrayList<>();
ZIMConversationBaseInfo info = new ZIMConversationBaseInfo();
info.conversationID = "convId";
info.conversationType = ZIMConversationType.PEER;
conversationInfos.add(info);

// Batch query conversation information
zim.queryConversations(conversationInfos, new ZIMConversationsQueriedCallback() {
    @Override
    public void onConversationsQueried(ArrayList<ZIMConversation> conversations, ArrayList<ZIMConversationBaseInfo> errorConversationInfos, ZIMError errorInfo) {
        // conversations is the list of successfully queried conversations
        // errorConversationInfos is the list of conversation base information that failed to be queried, based on which you can retry or degrade the process
    }
});

```
