### 设置离线推送规则

如需支持用户自定义推送规则时，开发者需要构造 {getPlatformData(props,ZIMUserOfflinePushRuleMap)}，规定用户在哪些平台上在线（[onlinePlatforms](@onlinePlatforms)）时，哪些平台无需接收离线推送（[notToReceiveOfflinePushPlatforms](@notToReceiveOfflinePushPlatforms)）。

自 3.3.0 版本起，{getPlatformData(props,ZIMUserOfflinePushRuleMap)} 新增以下字段：

| 字段 | 说明 |
| --- | --- |
| `offlinePushEnabled` | 离线推送总开关，默认开启。关闭后，消息和呼叫的离线推送均不下发。 |
| `messageOfflinePushEnabled` | 消息离线推送开关，默认开启。仅影响消息离线推送，不影响呼叫离线推送。 |
| `callOfflinePushEnabled` | 呼叫离线推送开关，默认开启。仅影响呼叫离线推送，不影响消息离线推送。 |
| `doNotDisturbRule` | 免打扰时间规则，规则生效期间，消息和呼叫的离线推送均不下发。详细请参考 [设置免打扰时间规则](#设置免打扰时间规则)。 |

调用 {getPlatformData(props,updateUserOfflinePushRuleMap)} 接口，设置上述规则。

:::if{props.platform=undefined}
```java
// 构造 ZIMUserOfflinePushRule
ArrayList<Integer> onlinePlatforms = new ArrayList<>();

// 当用户 win、MacOS、Linux 平台登录时
ArrayList<Integer> onlinePlatforms = new ArrayList<>();
onlinePlatforms.add(ZIMPlatformType.WIN.value());
onlinePlatforms.add(ZIMPlatformType.MAC_OS.value());
onlinePlatforms.add(ZIMPlatformType.LINUX.value());
offlineRule.setOnlinePlatforms(onlinePlatforms);

// 用户在 iPhoneOS、iPadOS、Android 上不收到离线推送
ArrayList<Integer> notToReceiveOfflinePushPlatforms = new ArrayList<>();
notToReceiveOfflinePushPlatforms.add(ZIMPlatformType.IPHONE_OS.value());
notToReceiveOfflinePushPlatforms.add(ZIMPlatformType.IPAD_OS.value());
notToReceiveOfflinePushPlatforms.add(ZIMPlatformType.ANDROID.value());
offlineRule.setNotToReceiveOfflinePushPlatforms(notToReceiveOfflinePushPlatforms);

// 离线推送总开关，默认开启（自 3.3.0 版本起支持）
offlineRule.setOfflinePushEnabled(true);
// 消息离线推送开关，仅影响消息离线推送，默认开启（自 3.3.0 版本起支持）
offlineRule.setMessageOfflinePushEnabled(true);
// 呼叫离线推送开关，仅影响呼叫离线推送，默认开启（自 3.3.0 版本起支持）
offlineRule.setCallOfflinePushEnabled(true);

// 调用 updateUserOfflinePushRule 方法
ZIM.getInstance().updateUserOfflinePushRule(offlineRule, new ZIMUserOfflinePushRuleUpdatedCallback() {
    @Override
    public void onUserOfflinePushRuleUpdated(ZIMUserOfflinePushRule updatedOfflinePushRule, ZIMError errorInfo) {
    }
});
```

### 设置免打扰时间规则

自 3.3.0 版本起，{getPlatformData(props,ZIMUserOfflinePushRuleMap)} 支持通过 `doNotDisturbRule` 字段设置免打扰时间规则。规则生效期间，消息和呼叫的离线推送均不下发。

[ZIMUserOfflinePushDoNotDisturbRule](@-ZIMUserOfflinePushDoNotDisturbRule) 字段说明如下：

| 字段 | 说明 |
| --- | --- |
| enabled | 是否启用免打扰规则。 |
| startHour / startMinute | 免打扰时段的开始时间，小时取值范围 [0, 23]，分钟取值范围 [0, 59]。 |
| endHour / endMinute | 免打扰时段的结束时间，小时取值范围 [0, 23]，分钟取值范围 [0, 59]。结束时间早于开始时间时，表示时段跨过零点，例如 22:00 至次日 08:00。 |
| repeatMode | 重复模式：<ul><li>`None`（1）：不重复，规则仅在保存当天生效。</li><li>`Daily`（2）：每天重复。</li><li>`Custom`（3）：自定义重复日，配合 `customRepeatDays` 使用。</li></ul>默认为 `Unknown`（未设置），SDK 会向服务端上报 0，规则仅在保存当天生效（不重复）。 |
| customRepeatDays | 自定义重复日，位掩码格式，bit0 表示周一，bit6 表示周日。仅在 `repeatMode` 为 `Custom` 时生效。 |
| onceEndTimestamp | 当 `repeatMode` 为 `None` 时，仅生效一次的免打扰时段结束的 UNIX 时间戳（秒），由服务端在保存规则时记录。**只读字段**，更新规则时传入的值会被忽略，由服务端重新计算。 |
| timeZoneID | 免打扰时段的 IANA 时区 ID，例如 "Asia/Shanghai"。空字符串表示未指定，服务端按 UTC 计算时段；非空时由服务端校验（非法 ID 返回错误码），并按该时区计算时段（感知夏令时）。如需跟随设备时区，请显式获取并传入本机 IANA 时区 ID。 |

:::if{props.platform=undefined}
```java
// 构造免打扰时间规则（自 3.3.0 版本起支持）
ZIMUserOfflinePushDoNotDisturbRule doNotDisturbRule = new ZIMUserOfflinePushDoNotDisturbRule();
doNotDisturbRule.setEnabled(true);
// 免打扰时段：每天 22:00 至次日 08:00
doNotDisturbRule.setStartHour(22);
doNotDisturbRule.setStartMinute(0);
doNotDisturbRule.setEndHour(8);
doNotDisturbRule.setEndMinute(0);
// 每天重复

// 时区，建议显式传入本机 IANA 时区 ID

    @Override
    public void onUserOfflinePushRuleUpdated(ZIMUserOfflinePushRule updatedOfflinePushRule, ZIMError errorInfo) {
    }
});
```
