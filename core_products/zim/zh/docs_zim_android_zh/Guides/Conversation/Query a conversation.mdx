# 查询会话

- - -

## 功能简介

ZIM 支持通过指定会话 ID 查询单个会话的详细信息，也支持批量查询多个指定会话的详细信息。

## 查询单个会话

用户登录后，可以调用 {getPlatformData(props,queryConversationMap)} 接口，指定会话 ID 及会话类型，获取对应会话的详细信息（包括会话名称、会话未读数、会话通知状态等）。

:::if{props.platform=undefined}
```java
String conversationID = "convId";
ZIMConversationType type = ZIMConversationType.PEER;

// 查询会话信息
zim.queryConversation(conversationID,type, new ZIMConversationQueriedCallback() {
    @Override
    public void onConversationQueried(ZIMConversation conversation, ZIMError errorInfo) {
        // 查询会话的信息。
    }
});

```

## 批量查询会话

自 3.3.0 版本起，ZIM 支持批量查询会话。

用户登录后，可以调用 {getPlatformData(props,queryConversationsMap)} 接口，传入待查询的会话基础信息（[ZIMConversationBaseInfo](@-ZIMConversationBaseInfo)）列表，一次性获取多个指定会话的详细信息（包括会话名称、会话未读数、会话通知状态等），无需多次调用 {getPlatformData(props,queryConversationMap)}。

- 单次最多可查询 100 个会话，登录后可用，登出后不可用。
- 查询成功的会话通过回调中的 `conversations` 返回，查询失败的会话基础信息通过 `errorConversationInfos` 返回，开发者可据此进行重试或降级处理。

:::if{props.platform=undefined}
```java
// 构造待查询的会话基础信息列表
ArrayList<ZIMConversationBaseInfo> conversationInfos = new ArrayList<>();
ZIMConversationBaseInfo info = new ZIMConversationBaseInfo();
info.conversationID = "convId";
info.conversationType = ZIMConversationType.PEER;
conversationInfos.add(info);

// 批量查询会话信息
zim.queryConversations(conversationInfos, new ZIMConversationsQueriedCallback() {
    @Override
    public void onConversationsQueried(ArrayList<ZIMConversation> conversations, ArrayList<ZIMConversationBaseInfo> errorConversationInfos, ZIMError errorInfo) {
        // conversations 为查询成功的会话列表
        // errorConversationInfos 为查询失败的会话基础信息列表，可据此重试或降级处理
    }
});

```
