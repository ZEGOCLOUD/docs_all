# ZIM 发布日志（适用于 HarmonyOS）

- - -

## 2.26.0 版本

**发布日期：2026-10-16**

<Note title="说明">

适用于 HarmonyOS 的 ZIM SDK 自 2.19.0 版本更新至 2.26.0 版本，支持使用 Flutter 框架开发 HarmonyOS 应用。功能对齐标准版 ZIM SDK 2.26.0 版本，包含 2.20.0 版本至 2.26.0 版本的全部新增功能与改进优化，详情请参考 [ZIM 发布日志](./ZIM%20release%20notes.mdx) 中 2.26.0 至 2.20.0 版本的发布日志。
</Note>

**新增功能**

|功能项-25% | 功能描述-40% | 相关接口-25%|
|-----|-----|-----|
|支持 HarmonyOS 平台| 支持使用 Flutter 框架开发 HarmonyOS 应用。此 SDK 需依赖 [适配 OpenHarmony 的 Flutter](https://gitee.com/openharmony-sig/flutter_flutter)，请在 [下载 SDK](./SDK%20downloads.mdx) 中获取 SDK 压缩包并以本地依赖方式集成，详情请参考 [实现基本消息收发 - 集成 SDK](./../Send%20and%20receive%20messages.mdx)。 | - |
