# ZIM Audio 发布日志（适用于 HarmonyOS）

- - -

## 1.0.4 版本

**发布日期：2026-10-16**

<Note title="说明">

- ZIM Audio SDK（适用 HarmonyOS 的版本）首次发布，支持使用 Flutter 框架在 HarmonyOS 应用中实现高清语音消息的收发，提供语音采集、播放、噪声抑制（ANS）、自动增益控制（AGC）等完整的语音处理能力。若需使用，请同时搭配 ZIM SDK 接入。
- 此版本所支持的语音处理功能与标准版 ZIM Audio SDK 1.0.0 版本一致，功能详情请参考 [ZIM Audio 发布日志](./ZIM%20Audio%20release%20notes.mdx) 中 1.0.0 版本的发布日志。
</Note>

**新增功能**

| 功能项-25% | 功能描述-40% | 相关接口-25% |
|-----|-----|-----|
|支持 HarmonyOS 平台| 支持使用 Flutter 框架开发 HarmonyOS 应用。此 SDK 需依赖 [适配 OpenHarmony 的 Flutter](https://gitee.com/openharmony-sig/flutter_flutter)，请在 [下载 SDK](./SDK%20downloads.mdx) 中获取 SDK 压缩包并以本地依赖方式集成，详情请参考 [语音组件 - 集成 SDK](./../ZIM%20Audio/Integrate%20the%20ZIM%20Audio%20SDK.mdx)。 | - |
