# 自定义推送规则

<Content />

## 实现流程

### 用户离线推送规则变化通知

如需在用户自定义规则时收到通知，请注册 [userRuleUpdated](@userRuleUpdated) 事件实现。

```typescript
// 监听用户自定义规则
zim.on('userRuleUpdated', (zim: ZIM, data: ZIMEventOfUserRuleUpdatedResult) => {
    // 离线推送规则
    const offlinePushRule = data.userRule.offlinePushRule;
});
```

### 设置离线推送规则

如需支持用户自定义推送规则时，开发者需要构造 [ZIMUserOfflinePushRule](@-ZIMUserOfflinePushRule) 类型参数，规定用户在哪些平台上在线（[onlinePlatforms](@onlinePlatforms)）时，哪些平台无需接收离线推送（[notToReceiveOfflinePushPlatforms](@notToReceiveOfflinePushPlatforms)）。

调用 [updateUserOfflinePushRule](@updateUserOfflinePushRule) 接口，设置上述规则。

自 3.3.0 版本起，[ZIMUserOfflinePushRule](@-ZIMUserOfflinePushRule) 新增以下字段：

| 字段 | 说明 |
| --- | --- |
| `offlinePushEnabled` | 离线推送总开关，默认开启。关闭后，消息和呼叫的离线推送均不下发。 |
| `messageOfflinePushEnabled` | 消息离线推送开关，默认开启。仅影响消息离线推送，不影响呼叫离线推送。 |
| `callOfflinePushEnabled` | 呼叫离线推送开关，默认开启。仅影响呼叫离线推送，不影响消息离线推送。 |
| `doNotDisturbRule` | 免打扰时间规则，规则生效期间，消息和呼叫的离线推送均不下发。 |

```typescript
// 设置离线推送规则

const offlinePushRule: ZIMUserOfflinePushRule = {
    // 当用户 Win、MacOS、Linux 平台登录时
    onlinePlatforms: [1, 4, 5],
    // 用户在 iPhoneOS、iPadOS、Android 上不收到离线推送
    notToReceiveOfflinePushPlatforms: [2, 3, 9],
    // 离线推送总开关，默认开启（自 3.3.0 版本起支持）
    offlinePushEnabled: true,
    // 消息离线推送开关，仅影响消息离线推送，默认开启（自 3.3.0 版本起支持）
    messageOfflinePushEnabled: true,
    // 呼叫离线推送开关，仅影响呼叫离线推送，默认开启（自 3.3.0 版本起支持）
    callOfflinePushEnabled: true,
    // 免打扰时间规则（自 3.3.0 版本起支持）
    doNotDisturbRule: {
        enabled: true,
        // 免打扰时段：每天 22:00 至次日 08:00
        startHour: 22,
        startMinute: 0,
        endHour: 8,
        endMinute: 0,
        // 每天重复
        repeatMode: 2,
        customRepeatDays: 0,
        onceEndTimestamp: 0,
        // 时区，建议显式传入本机 IANA 时区 ID
        timeZoneID: 'Asia/Shanghai',
    },
};

zim.updateUserOfflinePushRule(offlinePushRule)
    .then((res: ZIMUserOfflinePushRuleUpdatedResult) => {
        // success
    })
    .catch((err: ZIMError) => {
        // error
    });
```

<Note title="说明">

`doNotDisturbRule` 字段说明：

| 字段 | 说明 |
| --- | --- |
| enabled | 是否启用免打扰规则。 |
| startHour / startMinute | 免打扰时段的开始时间，小时取值范围 [0, 23]，分钟取值范围 [0, 59]。 |
| endHour / endMinute | 免打扰时段的结束时间。结束时间早于开始时间时，表示时段跨过零点，例如 22:00 至次日 08:00。 |
| repeatMode | 重复模式：`None`（1）不重复，规则仅在保存当天生效；`Daily`（2）每天重复；`Custom`（3）自定义重复日，配合 `customRepeatDays` 使用。 |
| customRepeatDays | 自定义重复日，位掩码格式，bit0 表示周一，bit6 表示周日。仅在 `repeatMode` 为 `Custom` 时生效。 |
| onceEndTimestamp | 当 `repeatMode` 为 `None` 时，仅生效一次的免打扰时段结束的 UNIX 时间戳（秒），由服务端记录。**只读字段**，更新时传入的值会被忽略。 |
| timeZoneID | 免打扰时段的 IANA 时区 ID，例如 "Asia/Shanghai"。空字符串表示按 UTC 计算；如需跟随设备时区，请显式传入本机 IANA 时区 ID。 |
</Note>

```typescript 
zim.querySelfUserInfo()

    });
```
