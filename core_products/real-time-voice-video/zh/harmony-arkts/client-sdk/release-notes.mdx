## 3.25.0 版本

**发布日期：2026-10-22**

<Warning title="注意">

Express SDK 3.25.0 版本更新了部分接口的参数类型，请参考 [升级指南](./upgrade-guide) 完成迁移。
</Warning>


**新增功能**

1. 支持媒体数据推流

    支持通过指定推流通道发布本地媒体文件（mp4 / m4a / aac，需专用工具转换），适用于 AI 课堂等服务端拉流场景。

    <Warning title="注意">
    需在创建引擎前设置引擎高级配置 ext_capture_and_inner_render=true（外部采集 + 内部渲染），并在开始推流前创建媒体数据推流器。
    </Warning>

    相关 API 请参考： [createMediaDataPublisher](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#createmediadatapublisher)、 [destroyMediaDataPublisher](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#destroymediadatapublisher)、 [ZegoMediaDataPublisher](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressdefines_.zegomediadatapublisher.html)、 [ZegoMediaDataPublisherConfig](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressdefines_.zegomediadatapublisherconfig.html)、 [ZegoMediaDataPublisherMode](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/enums/_zegoexpressdefines_.zegomediadatapublishermode.html)、 [onMediaDataPublisherFileOpen](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegomediadatapublisherlistener.html#onmediadatapublisherfileopen)、 [onMediaDataPublisherFileClose](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegomediadatapublisherlistener.html#onmediadatapublisherfileclose)、 [onMediaDataPublisherFileDataBegin](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegomediadatapublisherlistener.html#onmediadatapublisherfiledatabegin)、 [onMediaDataPublisherFileDataEnd](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegomediadatapublisherlistener.html#onmediadatapublisherfiledataend)

2. 支持通过监听音频数据回调获取原始 PCM 音频数据

    调用 startAudioDataObserver 并通过 ZegoAudioDataCallbackBitMask 按需开启回调，调用 stopAudioDataObserver 关闭。音频帧以 ArrayBuffer 形式回调，采样率与声道由 ZegoAudioFrameParam 指定。

    <Warning title="注意">
    [onPlayerAudioData](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onplayeraudiodata) 需处于拉流状态才会回调，且该回调不支持 8000 / 22050 / 24000 Hz 采样率。
    </Warning>

    相关 API 请参考： [startAudioDataObserver](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#startaudiodataobserver)、 [stopAudioDataObserver](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#stopaudiodataobserver)、[ZegoAudioFrameParam](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressdefines_.zegoaudioframeparam.html)、[ZegoAudioDataCallbackBitMask](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/enums/_zegoexpressdefines_.zegoaudiodatacallbackbitmask.html)、 [onCapturedAudioData](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#oncapturedaudiodata)、 [onPlaybackAudioData](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onplaybackaudiodata)、 [onMixedAudioData](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onmixedaudiodata)、 [onPlayerAudioData](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onplayeraudiodata)

3. 支持带 VAD（人声检测）的声浪信息回调

    在 startSoundLevelMonitor 中将 ZegoSoundLevelConfig.enableVAD 设为 true 后，可获取携带 VAD 状态的本地与远端声浪信息。

    相关 API 请参考： [startSoundLevelMonitor](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#startsoundlevelmonitor)

**改进优化**

1. 优化接口参数类型校验

    SDK 接口可选参数支持不传或传 null、undefined；参数类型不匹配时将返回明确的错误提示，便于快速定位问题。

2. 提升回调稳定性

    回调中未捕获的内部异常将被捕获并记录日志，避免内部异常导致应用崩溃。

3. 提升 SDK 稳定性，并升级底层音视频引擎

**问题修复**

1. 修复 [onRemoteSoundLevelInfoUpdate](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onremotesoundlevelinfoupdate) 回调声浪信息数据结构错误的问题，现与 [onRemoteSoundLevelUpdate](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onremotesoundlevelupdate) 保持一致。

2. 修复 [onPlayerRecvSEI](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onplayerrecvsei) 和 [onPlayerSyncRecvSEI](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpresseventhandler_.zegoeventlistener.html#onplayersyncrecvsei) 回调中可能出现的数据错乱或崩溃问题。

3. 修复 [startNetworkSpeedTest](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#startnetworkspeedtest) 解析 expectedDownlinkBitrate 配置错误，导致测速失败的问题。

4. 修复使用纹理渲染功能概率崩溃的问题。

5. 修复 [ZegoAudioEffectPlayer.loadResource](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressdefines_.zegoaudioeffectplayer.html#loadresource) 未返回实际错误码的问题。

## 1.2.0 版本 <a id="1.2.0"></a>

**发布日期：2024-11-07**

**新增功能**

1. 适配 HarmonyOS 发布版本

    该版本适配了 [HarmonyOS 5.0.0 Release](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases-V5/overview-V5)，对应 API 版本为 API 12 Release。接入过程可能会遇到系统特性导致的问题，详情请参考 [已知问题及解决方案](/real-time-video-harmonyos-arkts/introduction/known-issues-and-solutions)。


2. 新增 KTV 模块

    支持 KTV 点歌、版权内容中心曲库等能力。支持的版权音乐厂商包括音速达、音集协、网易。

3. 新增游戏语音模块

    主要包括：
    - 范围语音：房间内的收听者对音频的接收距离有范围限制，若发声者与自己的距离超过该范围，则无法听到声音。
    - 3D 音效：声音有 3D 空间感，且按距离衰减。
    - 小队语音：玩家可以选择加入小队，并支持在房间内自由切换“全世界”、“仅小队”、“隐秘小队”语音模式，不同模式下所能通话的范围不同。

    相关 API 请参考：[createRangeAudio](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressengine_.zegoexpressengine.html#createrangeaudio)、[ZegoRangeAudio](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressdefines_.zegorangeaudio.html)


4. 使用 HarmonyOS 系统的折叠屏手机，支持多摄像头自动选择功能

5. 视频编码格式支持使用 VP8 编码

**问题修复**

1. 修复已知问题
