# 升级指南

---

## 3.25.0 升级指南

<Warning title="注意">

Express SDK 3.25.0 版本更新了部分接口的参数类型，请参考以下说明完成迁移。
</Warning>

### 接口参数类型变更

1. `ZegoIMSendBroadcastMessageResult` 与 `ZegoBroadcastMessageInfo` 的广播消息 `messageID` 类型由 `number` 变更为 `bigint`

    广播消息 ID 超出 ArkTS `number` 类型的安全整数范围（2^53-1），改为端到端以 `bigint` 类型数据传输，无精度损失。
    
    <Note title="说明">
    弹幕消息 `messageID` 本身为 `string` 类型，不受影响。
    </Note>

    相关 API 请参考：[ZegoIMSendBroadcastMessageResult](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/interfaces/_zegoexpressdefines_.zegoimsendbroadcastmessageresult.html)、[ZegoBroadcastMessageInfo](https://doc-zh.zego.im/unique-api/express-video-sdk/zh/ets_ohos/classes/_zegoexpressdefines_.zegobroadcastmessageinfo.html)
