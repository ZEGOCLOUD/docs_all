# Interaction Mode: Full-Duplex, Listen-Only, Walkie-Talkie

## Scenario Overview

When interacting with the AI agent, there are three interaction forms that can be configured through the `AdvancedConfig.CommunicationMode` parameter when [creating an agent instance](/aiagent-server/api-reference/agent-instance-management/create-agent-instance):

| Interaction Form | Use Case | Common Scenarios |
| --- | --- | --- |
| Full-Duplex Mode (Default) | Free conversation scenarios where users can speak at any time and the AI responds instantly. | AI voice call |
| Listen-Only Mode | Continuous speech-to-text scenarios where AI listens without responding. | Cloud-based speech recognition, AI interviews, user content summarization |
| Walkie-Talkie Mode | On-demand short-turn interaction where users press to speak and release to receive AI responses. | Temporary speaking in online meetings, privacy protection in AI hardware |

## AI Agent Behavior Differences

| Dimension | Full-Duplex Mode | Listen-Only Mode | Walkie-Talkie Mode |
| --- | --- | --- | --- |
| User Speech Start/End Condition | Automatically detected by VAD segmentation | Automatically detected by VAD segmentation | Starts with StartListening, ends with StopListening; typically within 30 seconds |
| AI Speech Trigger | ✅ AI automatically replies after user finishes speaking<br />✅ Proactively speak via SendAgentInstanceTTS | ✅ Proactively speak via SendAgentInstanceTTS | ✅ AI automatically replies after listening ends<br />✅ Proactively speak via SendAgentInstanceTTS |
| ASR Callback | Result is sent after user finishes speaking | Every result matching segmentation rules is sent; a long listening session may generate multiple callbacks | Result is sent after StopListening |
| LLM Request | Requests LLM to generate a reply | Does not request LLM | Requests LLM to generate a reply |
| TTS | Broadcasts AI reply content | Does not automatically broadcast | Broadcasts AI reply content |
| Subtitles | Sent normally | Sent normally | Sent normally |

### Interaction Mode Switching

- Full-Duplex Mode (0) and Listen-Only Mode (1) can be switched between each other. The switch takes effect from the next user speech.
- Walkie-Talkie Mode (2) does not support switching to other modes.

## Implementation Steps

### Prerequisites
- Enable AI Agent service and complete the basic process according to [Quick Start Voice Call](/aiagent-server/quick-start).

### Implement Different Interaction Forms

<Tabs>
<Tab title="Full-Duplex Mode">
<Steps titleSize="p">
<Step title="Set interaction mode to full-duplex mode when creating instance">
Configure the `AdvancedConfig.CommunicationMode` parameter to 0 (default) when [creating an agent instance](/aiagent-server/api-reference/agent-instance-management/create-agent-instance) to enable full-duplex mode.

Refer to sections like [Speech Segmentation Control](/aiagent-server/advanced/speech-segmentation-control) and [Voice Activity Detection VAD Sensitivity](/aiagent-server/advanced/voice-interruption-sensitivity-adjustment) for more refined full-duplex interaction control.
</Step>
<Step title="(Optional) Update interaction mode to listen-only mode">
Call the [Update Agent Instance](/aiagent-server/api-reference/agent-instance-management/update-agent-instance) API to switch the interaction mode to listen-only. The switch takes effect from the next user speech.
</Step>
</Steps>
</Tab>
<Tab title="Listen-Only Mode">
<Steps titleSize="p">
<Step title="Set interaction mode to listen-only mode when creating instance">
Configure the `AdvancedConfig.CommunicationMode` parameter to 1 when [creating an agent instance](/aiagent-server/api-reference/agent-instance-management/create-agent-instance) to enable listen-only mode.

In listen-only mode, the AI will not automatically reply to the user. If you need the AI to proactively speak, you can trigger it by calling [Send Agent Instance TTS](/aiagent-server/api-reference/agent-instance-control/send-agent-instance-tts).

User speech content is returned through ASR callbacks, which can be used for subtitle display, content summarization, or keyword triggering.
</Step>
<Step title="(Optional) Update interaction mode to full-duplex mode">
Call the [Update Agent Instance](/aiagent-server/api-reference/agent-instance-management/update-agent-instance) API to switch the interaction mode to full-duplex. The switch takes effect from the next user speech.
</Step>
</Steps>
</Tab>
<Tab title="Walkie-Talkie Mode">
<Steps titleSize="p">
<Step title="Set interaction mode to walkie-talkie mode when creating instance">
Configure the `AdvancedConfig.CommunicationMode` parameter to 2 when [creating an agent instance](/aiagent-server/api-reference/agent-instance-management/create-agent-instance) to enable walkie-talkie mode.
</Step>
<Step title="Call server API to let AI listen to user speech">
Call the [StartListening](/aiagent-server/api-reference/agent-instance-control/start-listening) API to let the AI agent listen to user speech.
</Step>
<Step title="Call server API to let AI stop listening to user speech">
Call the [StopListening](/aiagent-server/api-reference/agent-instance-control/stop-listening) API to let the AI agent stop listening to user speech. After a normal stop, the AI will reply based on what the user said.

If you need to cancel the current listening session (without generating an AI reply), you can set `CancelFlag` to true when calling StopListening. This will stop ASR, discard cached audio and recognized results, not send ASR final-state callbacks, not request LLM/TTS, and not write to history. The Agent instance status will change from listening to idle.
</Step>
</Steps>

After completing a full cycle of letting AI listen to user speech and then stopping listening, the AI will reply based on what the user said🎉.
</Tab>
</Tabs>
