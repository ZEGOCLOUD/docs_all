<h1 className={"openapi__heading"}>CreateAgentInstance</h1>

<MethodEndpoint method={"post"} path={"/"}></MethodEndpoint>


By calling this interface, you can create an AI agent instance and add it to a voice (RTC) conversation.

<Warning title="Note">
1. If there is no real user in the RTC room after 120 seconds, the AI agent instance will automatically be destroyed, and the Event will be AgentInstanceDeleted [callback](/aiagent-server/callbacks/receiving-callback), and the Data.Code will be 1202.
2. By default, each account can have at most 10 AI agent instances. If the limit is exceeded, the creation of an AI agent instance will fail. If you need to adjust this limit, please contact ZEGOCLOUD Technical Support.
</Warning>
