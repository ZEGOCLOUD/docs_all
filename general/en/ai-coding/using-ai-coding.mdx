# Using AI Coding

With AI coding agents, you can integrate ZEGO products and fix issues far more efficiently. ZEGO provides a ready-to-use **Agent Skill (zego-integration)** for all major AI coding tools: once installed, the agent automatically loads ZEGO domain knowledge, the full official docs index, and standard integration workflows whenever it handles a ZEGO-related task — resulting in more accurate product integration, bug fixing, and troubleshooting.

## Landscape of AI Coding Agents <a id="agent-overview" />

AI coding agents have evolved from "code completion" into agents that can execute complete engineering tasks end to end: understand requirements → plan → read & write code → run and verify → self-correct. Mainstream tools fall into two categories:

- **Terminal CLIs**: Claude Code, Codex CLI, Gemini CLI, DeepSeek Harness, etc. They work directly in your project terminal and suit complex engineering tasks and automation.
- **IDE / editor-integrated**: Cursor, Windsurf, Trae, Augment, CodeBuddy, etc. They bring agent capabilities into a graphical environment for day-to-day development.

Most of these tools support the open **Agent Skills** standard (the SKILL.md format): the same skill package can be loaded by any of them — install once, works everywhere.

## How It Works <a id="how-it-works" />

An AI coding agent is a "LLM + tool calling" loop: the model reads your codebase and requirements, then works step by step through tools such as reading/writing files, running commands, and searching. Limited by its context window, the model cannot know every product's specifics — relying on general training memory alone tends to produce outdated API usage or hallucinations.

Agent Skills solve this by **injecting domain knowledge on demand**:

1. Each skill declares its applicable scenarios in `SKILL.md`; the agent loads it only when the task matches, consuming no everyday context.
2. The skill bundles reference material and scripts; the agent reads deeper as needed, forming a knowledge map of "where to look".
3. zego-integration caches the ZEGO official docs repo locally, so the agent **searches** instead of "recalling" — every API, parameter, and error code it cites comes from the latest official docs, not a stale snapshot in model memory.

## Install and Use the Skill <a id="install" />

Pick any of the following (distributed from the GitHub repo [ZEGOCLOUD/zego-integration](https://github.com/ZEGOCLOUD/zego-integration)).

**Option 1: skills CLI (recommended)**

```bash
npx skills add ZEGOCLOUD/zego-integration
```

Auto-detects your installed AI coding tools and installs to the right locations.

**Option 2: one-line script**

```bash
curl -fsSL https://raw.githubusercontent.com/ZEGOCLOUD/zego-integration/main/install.sh | bash
```

For restricted networks (no direct GitHub access), use the mirror:

```bash
curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/ZEGOCLOUD/zego-integration/main/install.sh | bash
```

**Option 3: manual clone**

```bash
git clone https://github.com/ZEGOCLOUD/zego-integration.git ~/.agents/skills/zego-integration
```

**Option 4: DeepSeek Harness plugin** <a id="dsh-install" />

Open DeepSeek Harness, click **Plugins** → **Add Plugin**, enter `https://github.com/ZEGOCLOUD/dsh-zego-assistant` in the input box, and click **Install**. Then just raise ZEGO tasks in natural language; if the skill doesn't activate, restart the current profile. The plugin bundles the zego-integration skill and keeps it in sync with upstream automatically — no extra configuration.

For options 1–3, choose the directory matching your tool: `~/.agents/skills/` (cross-tool shared), `~/.claude/skills/` (Claude Code), `~/.codex/skills/` (Codex CLI), etc. See the repo [README](https://github.com/ZEGOCLOUD/zego-integration#installation) for details.

### Use It <a id="usage" />

Restart your agent session after installation, then just describe what you need in natural language:

- "Build a 1v1 video call with ZEGO in Next.js"
- "What does error code 1230004 mean, and how do I fix it?"
- "What are the parameters of loginRoom? Any differences between Web and Android?"
- "How do I generate token04 on the server side? Give me a Go implementation"

On first use, the skill downloads a docs snapshot and caches it locally (`~/.cache/zego-integration/`), then updates incrementally as needed; China-mainland networks automatically go through mirrors — no extra configuration needed.

## Best Practices <a id="best-practices" />

- State the ZEGO product and platform clearly in your prompt (e.g. "Video Call, Android Java").
- Include as many concrete requirements as possible so the agent understands the goal.
- When something fails, describe the symptom clearly and attach error logs or screenshots for accurate diagnosis.
