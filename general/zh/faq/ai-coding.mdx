# 使用AI Coding

借助 AI Coding（AI 编程工具），可以高效完成 ZEGO 产品的集成与问题修复。我们为各类 AI 编程工具提供了开箱即用的 Skills，安装后 AI 会自动获取 ZEGO 产品领域知识与标准工作流程，并调用 ZEGO 文档 [MCP](https://modelcontextprotocol.io/docs/getting-started/intro) 服务查阅官方文档，从而更精准地完成集成 ZEGO 产品或者修复与 ZEGO 相关 Bug 的任务。

## Skill能力说明 <a id="skill-capabilities" />

由 AI 编程工具智能触发、按需加载的能力扩展包，会在合适的场景自动为 AI 注入 ZEGO 产品领域知识与标准工作流程。

| 能力 | 说明 |
| --- | --- |
| 产品集成 | 引导完成 ZEGO 产品选型、平台选择与集成实施 |
| 服务端 Token 生成 | 提供多语言服务端 Token 生成示例代码 |
| 服务端 API 调用 | 包含签名机制说明与多语言调用示例 |
| 资源下载 | 下载 SDK、示例项目、示例代码等资源 |
| 知识问答与排障 | 基于官方文档的知识问答，支持错误码、接口用法等线上问题排查 |

<Note title="说明">以上为当前支持的能力，未来还会持续增加。</Note>

## 步骤1：安装Skill <a id="skills-and-rules-file" />

ZEGO 文档 MCP 服务需要配合 Skill 使用才能获得更好的效果：会引导 AI 在集成 ZEGO 产品或排查问题时优先调用 ZEGO 文档 MCP 工具查阅官方文档，然后再进行开发工作。

如果您使用的 AI 编程工具没有对应的插件，请手动将 [skills 目录](https://github.com/ZEGOCLOUD/zego-claude-code-plugins/tree/main/plugins/zego-assistant/skills)下所有 Skill 下载到对应工具的配置文件夹下。

## 步骤2：配置 ZEGO 开发者文档 MCP<a id="configure-zego-mcp-server" />

ZEGO 文档 MCP 服务器使用的是 HTTP 协议，配置如下：
```json
{
  "mcpServers": {
    "ZEGO": {
      "url": "https://doc-ai.zego.im/mcp/"
    }
  }
}
```

具体各种 IDE 的 MCP 服务配置方法请参考对应说明文档进行设置：

<Note title="说明">仅列出一些热门 IDE 的 MCP 服务配置方法，其他 IDE 的配置方法请参考对应说明文档。</Note>

- [Augment Code](https://docs.augmentcode.com/jetbrains/setup-augment/mcp)
- [Cursor](https://cursor.com/cn/docs/context/mcp#installing-mcp-servers)
- [Claude Code](https://code.claude.com/docs/en/mcp#option-1:-add-a-remote-http-server)（建议直接使用我们提供的 Claude Code 插件自动配置 MCP 服务，详见下文 [Claude Code 插件](#claude-code-configuration) 章节。）
- [CodeBuddy](https://www.codebuddy.ai/docs/zh/ide/Config%20MCP#%E8%87%AA%E5%AE%9A%E4%B9%89%E9%85%8D%E7%BD%AE-mcp-server)
- [Trae](https://docs.trae.ai/ide/model-context-protocol?_lang=zh#0b1e1b2c)
- [DeepSeek Harness](https://www.deepseek.com/harness/)（建议通过我们提供的 dsh 插件自动配置 MCP 服务，详见上文 [DeepSeek Harness插件](#deepseek-harness-configuration) 章节。）

## 其他集成方式

### Claude Code 插件 <a id="claude-code-configuration" />

如果您使用的是 Claude Code，建议直接安装我们提供的 [ZEGO Claude Code Plugins](https://github.com/ZEGOCLOUD/zego-claude-code-plugins)，插件会自动安装 ZEGO 相关 Skills 并配置 ZEGO 文档 MCP 服务。

<Video src="https://doc-media.zego.im/general/zh/faq/zego-claude-code-plugin.mp4" />

### DeepSeek Harness插件 <a id="deepseek-harness-configuration" />

如果您使用的是 [DeepSeek Harness](https://www.deepseek.com/harness/)，请安装我们提供的 [dsh-zego-assistant](https://github.com/ZEGOCLOUD/dsh-zego-assistant) 插件（已发布至 GitHub 和 npm）。插件会自动配置 ZEGO 文档 MCP 服务并安装 ZEGO 相关 Skills，安装并重启对应的 profile 后，在"设置 > 插件 > 插件列表"中可以看到 zego-assistant 和 mcp-client 均处于"已启用"状态，即表示安装成功：

```bash
dsh plugin --profile web add dsh-zego-assistant
```

## 最佳实践 <a id="best-practices" />

- 给 AI 的提示词应该尽可能说清楚使用到的 ZEGO 相关的产品名称及平台。
- 给 AI 的提示词应该包含尽可能多的细节要求，以便 AI 能够更好地理解用户需求。
- 如果集成后或出现错误，请把错误现象描述清楚并且配上错误日志或错误信息截图以便 AI 能够更好地定位问题。
