# 使用 AI Coding

借助 AI Coding（AI 编程智能体），可以高效完成 ZEGO 产品的集成与问题修复。ZEGO 为各类 AI 编程工具提供了开箱即用的 **Agent Skill（zego-integration）**：安装后，AI 会在处理 ZEGO 相关任务时自动加载 ZEGO 产品领域知识、官方文档索引与标准集成工作流程，从而更精准地完成产品集成、Bug 修复与问题排查。

## AI 编程智能体现状 <a id="agent-overview" />

AI 编程智能体已经从"代码补全"进化为可以独立执行完整工程任务的智能体：理解需求 → 规划方案 → 读写代码 → 运行验证 → 自我修正。当前主流工具分为两类：

- **终端 CLI 形态**：Claude Code、Codex CLI、Gemini CLI、DeepSeek Harness 等，直接在项目终端中工作，适合复杂工程任务与自动化流程。
- **IDE / 编辑器形态**：Cursor、Windsurf、Trae、Augment、CodeBuddy 等，在图形界面中提供 Agent 能力，适合日常开发。

这些工具普遍支持开放的 **Agent Skills** 标准（SKILL.md 格式）：同一个 Skill 包可以被上述任意工具加载，一次安装、全工具通用。

## 工作原理 <a id="how-it-works" />

AI 编程智能体的核心是"大模型 + 工具调用"循环：模型阅读代码库与需求，通过读文件、写文件、执行命令、检索等工具逐步完成任务。受上下文窗口限制，模型无法预知所有产品知识——仅靠通用训练记忆，容易给出过时的 API 用法甚至凭空编造。

Agent Skill 通过**按需注入领域知识**解决这个问题：

1. 每个 Skill 以 `SKILL.md` 声明自己的适用场景，AI 只在任务匹配时才加载它，不占用日常上下文。
2. Skill 内置参考资料与脚本，AI 按需深入读取，形成"知道去哪查"的知识地图。
3. zego-integration 会把 ZEGO 官方文档仓库缓存到本地，AI 用**检索**代替"记忆"——查到的接口、参数、错误码均来自最新官方文档，而非模型训练时的记忆快照。

## Skill 能力说明 <a id="skill-capabilities" />

| 能力 | 说明 |
| --- | --- |
| 产品集成 | 引导完成 ZEGO 产品选型、平台选择与集成实施 |
| 文档查阅 | 官方文档全量本地缓存，支持错误码、接口参数、平台兼容性查询，支持公网 URL 与文档内容互查 |
| 服务端 Token 生成 | token04 生成规范与多语言服务端示例代码 |
| 服务端 API 调用 | 签名机制说明与多语言调用示例 |
| 资源下载 | 下载 SDK、示例项目、示例代码等资源（内置国内镜像回退） |
| 场景最佳实践 | Web / iOS / Android 等场景的实战经验与踩坑指引，持续扩充 |

<Note title="说明">以上为当前支持的能力，未来还会持续增加。</Note>

## 安装和使用 Skill <a id="install" />

任选一种方式安装（分发源为 GitHub 仓库 [ZEGOCLOUD/zego-integration](https://github.com/ZEGOCLOUD/zego-integration)）。

**方式一：skills CLI（推荐）**

```bash
npx skills add ZEGOCLOUD/zego-integration
```

自动探测本机已安装的 AI 编程工具，并安装到对应位置。

**方式二：一键脚本**

```bash
curl -fsSL https://raw.githubusercontent.com/ZEGOCLOUD/zego-integration/main/install.sh | bash
```

网络受限（无法直连 GitHub）时使用镜像：

```bash
curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/ZEGOCLOUD/zego-integration/main/install.sh | bash
```

**方式三：手动 clone**

```bash
git clone https://github.com/ZEGOCLOUD/zego-integration.git ~/.agents/skills/zego-integration
```

**方式四：DeepSeek Harness 插件** <a id="dsh-install" />

打开 DeepSeek Harness，点击 **插件** → **添加插件**，在输入框输入 `https://github.com/ZEGOCLOUD/dsh-zego-assistant` 后点击 **安装** 即可。安装完成后直接用自然语言提 ZEGO 相关需求；如技能未生效，重启当前 profile。插件内置 zego-integration Skill 并随上游自动更新，无需其他配置。

方式一~三的安装目录按所用工具而定：`~/.agents/skills/`（跨工具共享）、`~/.claude/skills/`（Claude Code）、`~/.codex/skills/`（Codex CLI）等，详见仓库 [README](https://github.com/ZEGOCLOUD/zego-integration#installation)。

### 使用 <a id="usage" />

安装后重启 AI 编程工具会话，直接用自然语言提需求即可，例如：

- "帮我用 ZEGO 在 Next.js 里实现一个 1v1 视频通话"
- "查一下错误码 1230004 是什么意思，怎么处理"
- "loginRoom 有哪些参数？Web 和 Android 版有什么差异？"
- "服务端怎么生成 token04？给我一个 Go 实现"

首次使用时，Skill 会自动下载文档快照并缓存在本地（`~/.cache/zego-integration/`），之后按需增量更新；国内网络会自动走镜像通道，无需额外配置。

## 最佳实践 <a id="best-practices" />

- 提示词应尽可能说清楚使用的 ZEGO 产品名称及平台（如"实时音视频，Android Java 版"）。
- 提示词应包含尽可能多的细节要求，以便 AI 更好地理解需求。
- 出现错误时，把错误现象描述清楚并附上错误日志或错误信息截图，以便 AI 更准确地定位问题。
